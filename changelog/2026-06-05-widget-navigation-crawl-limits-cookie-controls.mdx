This release makes customer-facing Brand Agents more dependable across page changes and reloads. It also gives you clearer knowledge base limits, safer file uploads, and more control over cookie preferences.

## TL;DR

- **Persistent website conversations:** Visitors can continue a Brand Agent conversation after reloading the page.
- **Smoother page navigation:** Brand Agents can guide visitors to another page without unnecessarily closing the chat.
- **Safer uploads:** Brand Agent file uploads are limited to images and PDFs.
- **Clearer crawl limits:** Free-plan users receive a clear upgrade prompt when a website crawl reaches the 24-page limit.
- **Better cookie controls:** Visitors can accept, reject, or customize non-essential cookies and reopen their preferences later.
- **More reliable verification:** Sign-up guidance now reminds users to check spam when a verification email is missing.

---

## What's new

### 1) Website conversations that survive reloads and navigation

Brand Agent widgets now preserve more of the visitor's experience while they move around your website:

- **Conversation restore:** A visitor can reload the page and continue the same widget conversation.
- **In-site navigation:** When a Brand Agent directs someone to another page on the same website, supported sites can keep the widget open during the transition.
- **Completed navigation replies:** The agent can finish and save its response before the page changes.
- **Cleaner navigation prompts:** Page-navigation actions appear separately from technical tool activity, making the chat easier to follow.

**Why it matters:** Visitors can explore your website without repeatedly losing context or restarting their conversation.

---

### 2) Safer Brand Agent file uploads

Customer-facing upload options are now more focused:

- **Supported uploads:** Brand Agent visitors can attach images and PDF documents.
- **Clearer boundaries:** Other file types are excluded from the public-facing upload flow.
- **More reliable loading:** Widget startup and conversation restoration handle overlapping requests more consistently.

**Why it matters:** Your public agent receives useful visual and document context through a simpler, safer upload experience.

---

### 3) Clearer knowledge base crawl limits

Website crawling now gives Free-plan users better feedback:

- **24-page Free-plan limit:** Website knowledge base crawls on the Free plan support up to 24 pages.
- **Visible limit state:** If a crawl reaches the plan limit, the interface explains what happened.
- **Upgrade path:** The limit message provides a direct route to plans with higher allowances.

**Why it matters:** You can understand why a crawl stopped and decide whether to narrow the source or upgrade for a larger website.

---

### 4) More useful cookie preferences

Cookie consent is easier for visitors to control:

- **Three clear choices:** Visitors can accept all cookies, reject non-essential cookies, or customize preferences by category.
- **Saved preferences:** Choices persist for future visits.
- **Cookie settings link:** Visitors can reopen their preferences from the website footer.
- **Production-only analytics:** Production analytics are kept separate from staging activity.

**Why it matters:** Visitors get understandable privacy controls, while site analytics respect the preferences they select.

## How to use (quick steps)

### Test conversation restoration

1. Open your published **Brand Agent** widget and send a message.
2. Reload the page.
3. Reopen the widget and confirm that the conversation continues.

### Review a website crawl limit

1. Create or edit a **Knowledge Base** using a website source.
2. Start the crawl and monitor its progress.
3. If the Free-plan page limit is reached, follow the on-screen guidance to refine the source or review upgrade options.

### Change cookie preferences

1. Choose **Accept all**, **Reject non-essential**, or **Customize** when the cookie notice appears.
2. To change the choice later, open **Cookie settings** in the website footer.

## FAQ

**Will a visitor's widget conversation return after a page reload?**
Yes. The widget can restore the existing conversation so the visitor does not have to start again.

**Does navigation always reload the website?**
Not necessarily. Supported same-site navigation can move visitors between pages while keeping the widget open. Other destinations may still require a normal page load.

**Which files can visitors upload to a Brand Agent?**
The customer-facing Brand Agent upload flow supports images and PDFs.

**What happens when a Free-plan crawl reaches 24 pages?**
The crawl interface shows that the plan limit was reached and provides an upgrade path. You can also narrow the website source to stay within the limit.

**Can visitors change their cookie preferences later?**
Yes. They can reopen **Cookie settings** from the website footer.
