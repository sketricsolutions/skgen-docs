This smaller release makes Brand Agent templates open through the right setup experience and improves Agent Space navigation on mobile devices.

- **Dedicated Brand Agent template flow:** Brand Agent templates now open the appropriate Brand Agent setup instead of being treated like a standard AI Workforce template.
- **Correct template links:** Template cards and calls to action now send both signed-in and signed-out visitors to the intended destination.
- **Better mobile editing:** Agent Space navigation and editor layouts behave more reliably on smaller screens.
- **More consistent template metadata:** Brand Agent templates use the same public content and search metadata expected across the template catalog.

**Why it matters:** You can choose a Brand Agent template with confidence and continue configuring agents more comfortably from a mobile device.
