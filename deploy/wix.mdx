The **SketricGen Brand Agent** app is the recommended way to add a Brand Agent to Wix. It connects your site without code or an embed snippet and displays the widget across your published site. Manual embed options remain available for custom layouts.

<Tabs>
  <Tab title="Wix App (Recommended)">

  ## Before you start

  You need:

  - A SketricGen account with at least one Brand Agent. If you do not have one yet, [create a Brand Agent](/brand-agents/create-brand-agent).
  - Wix permission to install or manage apps and publish the site. A site owner, co-owner, or collaborator with an appropriate custom role can complete the setup.

  ## Step 1: Make your Brand Agent public and published

  In SketricGen, open your Brand Agent and select the **Deploy** tab.

  1. Set **Visibility** to **Public**. The page confirms that your agent is publicly accessible.
  2. Select **Publish Now** if the agent has unpublished changes.

  ![SketricGen Brand Agent Deploy tab showing Public visibility and the Publish Now button](/images/product-ui-2026/wix-app/step-1-public-and-publish.png)

  > **Note:** Wix lists only Brand Agents that are active, published, set to **Public**, and editable by your account. If an agent is missing from the connection list, verify these settings before trying again.

  ## Step 2: Open the Wix App Market

  From your Wix site dashboard, go to **Apps → App Market**.

  ![Wix site dashboard with Apps expanded and App Market selected](/images/product-ui-2026/wix-app/step-2-app-market.png)

  ## Step 3: Find the SketricGen Brand Agent app

  Search for **SketricGen**, then select **SketricGen Brand Agent** from the results.

  ![Wix App Market search showing the SketricGen Brand Agent app](/images/product-ui-2026/wix-app/step-3-search-sketricgen.png)

  ## Step 4: Add the app to your site

  On the app page, select **Add to Site** and accept the permissions requested by Wix. The app is free to install.

  ![SketricGen Brand Agent listing in the Wix App Market with the Add to Site button](/images/product-ui-2026/wix-app/step-4-add-to-site.png)

  ## Step 5: Start the connection

  The app appears in your dashboard under **Apps → SketricGen Brand Agent**. Open it, then select **Connect Brand Agent** in **01 Connect your Brand Agent**. A SketricGen window opens.

  ![SketricGen Brand Agent setup page in Wix showing the Connect Brand Agent button](/images/product-ui-2026/wix-app/step-5-connect-brand-agent.png)

  > **Note:** If the connection window does not open, allow popups for Wix and select **Connect Brand Agent** again.

  ## Step 6: Sign in to SketricGen

  Sign in with the account that can edit the Brand Agent you want to connect. Continue with Google or your email address.

  ![SketricGen sign-in window opened from Wix with Google and email sign-in options](/images/product-ui-2026/wix-app/step-6-sign-in-redacted.png)

  ## Step 7: Choose and connect your Brand Agent

  Open the **Brand Agent** list and select the agent you want to use. Each entry includes its Teamspace and Project so that you can distinguish agents with similar names. Then select **Connect agent**.

  ![SketricGen connection window with a Brand Agent selected from the list](/images/product-ui-2026/wix-app/step-7-select-agent-redacted.png)

  After the connection succeeds, the Wix setup page displays **Connected and ready** with the connected agent ID.

  ## Step 8: Choose the launcher and enable the widget

  Under **02 Customize the widget**, choose how visitors open the Brand Agent:

  - **Chat bubble:** A compact launcher in the bottom-right corner.
  - **Floating pill:** A message field centered along the bottom of the page.

  Under **03 Publish to your website**, set **Show Brand Agent widget** to **On**.

  ![Wix app settings showing the Chat bubble launcher selected and the Brand Agent widget enabled](/images/product-ui-2026/wix-app/step-8-launcher-and-toggle.png)

  ## Step 9: Publish and test your site

  Publish your site from the Wix editor, then open the live site. The Brand Agent widget appears with the welcome message configured in SketricGen.

  ![Published Wix site with the SketricGen Brand Agent widget open](/images/product-ui-2026/wix-app/step-9-live-site.png)

  **Success:** Your Brand Agent is live on Wix.

  ## Customize the widget

  Appearance, welcome message, suggested questions, knowledge, and behavior are managed in SketricGen. From the Wix app, select **Open Brand Agent Editor**, or open the agent directly at [sketricgen.ai](https://www.sketricgen.ai), and then select **Customize Widget**.

  Publish changes in SketricGen to send them to the live Wix widget without republishing your Wix site.

  > **Note:** The launcher style is stored in Wix. After switching between **Chat bubble** and **Floating pill**, publish the Wix site again.

  ## Change, hide, or disconnect the agent

  From the app setup page:

  - **Change agent:** Connect a different Brand Agent to the site.
  - **Disconnect:** Unlink the agent and remove its widget. The Brand Agent and its content remain in SketricGen.
  - **Show Brand Agent widget → Off:** Hide the widget without disconnecting the agent.

  Publish the Wix site after changing any of these settings.

  ## Troubleshooting

  **My agent is not in the list.** Confirm that the agent is active, published, set to **Public**, and editable by your account. Return to [Step 1](#step-1-make-your-brand-agent-public-and-published), correct the settings, and reconnect.

  **I see "Reconnect required."** Select **Change agent**, then choose the agent again to finish secure linking.

  **The connection window opened blank and closed.** Sign in to [sketricgen.ai](https://www.sketricgen.ai) in the same browser, then retry the connection.

  **The widget is missing from my live site.** Confirm that **Show Brand Agent widget** is **On**, then publish the Wix site.

  **I signed in to the wrong SketricGen account.** Select **Sign out** in the connection window, then sign in with the account that can edit the agent.

  **I cannot install the app or publish the site.** Ask the Wix site owner to install the app or grant you a role that can manage apps and publish the site.

  <Tab title="Floating Chat Bubble (Manual)">

  ## **Step 1: Create your SketricGen account**

    To get started with the integration, **[sign in to your SketricGen account](https://www.sketricgen.ai)**. If you don’t have an account yet, you can create one for **[free](https://www.sketricgen.ai)**. Once you're logged in, begin setting up your Brand Agent by uploading your data sources. These can include files, text snippets, websites, or Q&A pairs, which will serve as the knowledge base for your Brand Agent.

    Use this path when you want a Wix website chatbot for lead capture, visitor support, product guidance, or sales questions.

    If you need assistance with setting up a working SketricGen Brand Agent, refer to the **[step-by-step guide](https://docs.sketricgen.ai/getting-started/quickstart)** for creating and deploying your Brand Agent.

    ## **Step 2: Copy the SketricGen Brand Agent Embed Code**

  Open your Brand Agent and select **Deploy**. Set **Visibility** to **Public**, publish any pending changes, select **Chat Bubble**, and copy the embed code.

  ![SketricGen Brand Agent Deploy tab with Public visibility and Chat Bubble selected](/images/product-ui-2026/wix-app/step-1-public-and-publish.png)

  ## **Step 3: Embed the Brand Agent in Wix**

  ### 1. Log in to your Wix dashboard.
  ### 2. Select the site where you want the Brand Agent.

     ![Screenshot showing Wix dashboard with site selection interface](/images/wix/screenshot2.png)

  ### 3. Go to **Add Elements > Embed & Social > Embed Code**.

     ![Screenshot showing Wix Add Elements interface with Embed & Social > Embed Code option](/images/wix/screenshot3.png)

  ### 4. Paste the copied code and adjust position/size as needed.

     ![Screenshot showing Wix Embed Code element with code input and positioning options](/images/wix/screenshot4.png)

  ### 5. Resize the **Embed Code** element so the full chat widget is visible.

     Click the embedded widget and adjust the element’s **width/height** (or drag the resize handles) until nothing is clipped and the chat opens at the correct size.

     ![GIF showing how to resize the Embed Code element in Wix](/images/wix/gif1.gif)

  ### 6. Add an **Anchor** and **Pin** the Brand Agent widget to make it a floating bubble.

     ![Screenshot showing Wix Anchor and Pin options for floating chat bubble configuration](/images/wix/screenshot5.png)

  ## **Step 4: Test the Brand Agent**

  After publishing, test the Brand Agent on your live site.

  ![Screenshot showing Wix site with embedded SketricGen floating chat widget](/images/wix/screenshot6.png)

  **Success:** Your Brand Agent is live as a floating bubble on Wix.

  ## **Step 1: Create your SketricGen account**

    To get started with the integration, **[sign in to your SketricGen account](https://www.sketricgen.ai)**. If you don’t have an account yet, you can create one for **[free](https://www.sketricgen.ai)**. Once you're logged in, begin setting up your Brand Agent by uploading your data sources. These can include files, text snippets, websites, or Q&A pairs, which will serve as the knowledge base for your Brand Agent.

    Use this path when you want to place a Brand Agent directly inside a Wix page section.

  ## **Step 2: Get the Embed Code**

  Open your Brand Agent and select **Deploy**. Set **Visibility** to **Public**, publish any pending changes, select **iframe/Fullscreen**, and copy the iframe code.

  ![SketricGen Brand Agent Deploy tab with Public visibility and iframe Fullscreen available](/images/product-ui-2026/wix-app/step-1-public-and-publish.png)

  ## **Step 3: Add the iFrame Embed to Wix**

  ### 1. Go to your Wix site dashboard.
  ### 2. Select the desired site.

     ![Screenshot showing Wix dashboard with site selection interface](/images/wix/screenshot2.png)

  ### 3. Add an **Embed Code** element:
     **Add Elements > Embed & Social > Embed Code**

     ![Screenshot showing Wix Add Elements interface with Embed & Social > Embed Code option](/images/wix/screenshot3.png)

  ### 4. Paste your code and adjust dimensions for inline display.

     ![Screenshot showing Wix Embed Code element with iframe code and dimension adjustments](/images/wix/screenshot8.png)

  ## **Step 4: Publish and Verify**

  Make sure everything is working by testing the Brand Agent on your live site.

  ![Screenshot showing Wix site with embedded SketricGen iframe widget](/images/wix/screenshot9.png)

  **Success:** Your Brand Agent is embedded inline in your Wix site.
