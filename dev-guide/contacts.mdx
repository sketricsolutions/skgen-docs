---
title: "Contact ID"
description: "Use contact_id to group SketricGen conversations under users or contacts from your own system."
---

Contact ID connects SketricGen conversations to a stable user or contact identifier from your own system.

Where to go next:

- If you are using the REST API, SDKs, AI Workforce, or a custom product integration, see [Runtime API: Contact ID and User Grouping](/dev-guide/public-api-usage#contact-id-and-user-grouping).
- If you are adding the chat bubble or iframe to a website, see [How Widget Visitors Are Identified](/deploy/custom-website#how-widget-visitors-are-identified).

In short:

- Runtime API requests use `contact_id` in the JSON body.
- Embedded widgets, iframes, and fullscreen links receive a contact identity assigned by SketricGen. They ignore `data-contact-id` and the `contactId` query parameter, because a page-supplied identifier could not be trusted as a visitor identity.

When you send `contact_id` through the Runtime API, use a stable internal ID, UUID, or hashed value. Avoid emails, phone numbers, names, or other directly identifiable personal data.
