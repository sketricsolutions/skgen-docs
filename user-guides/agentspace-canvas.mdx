SketricGen now separates the live operational workplace from the internal agent editor.

## Current Product Surfaces

- [Agent Space](/ai-workforce/agent-space) shows agents, active work, schedules, teammates, and human-input requests across the selected Project.
- [Agent Build](/ai-workforce/agent-build) configures the main agent, sub-agents, instructions, models, tools, skills, and handoffs.
- [Playground](/ai-workforce/playground) runs and tests the agent through conversations, files, artifacts, traces, and human input.

Older documentation used **Agent Space** for the visual builder. The current product calls that editor **Agent Build**.

If you are building a public website agent, start with [Create a Brand Agent](/brand-agents/create-brand-agent).
