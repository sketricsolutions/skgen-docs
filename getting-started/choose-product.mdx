SketricGen provides two agent types for different environments:

- **Brand Agents** are public, customer-facing agents for websites and external channels.
- **AI Workforce** agents operate inside a permissioned Teamspace and Project for more powerful internal work.

Choose based on who will use the agent and what access it needs—not simply which agent sounds more advanced.

## Quick Decision

Choose a **Brand Agent** when customers should talk directly to the agent. Choose **AI Workforce** when you and your team need agents to perform substantial work with files, plans, tools, business systems, and other agents.

| Difference | Brand Agents | AI Workforce |
| --- | --- | --- |
| Primary users | Website visitors, prospects, leads, and customers | You and authorized Teamspace members |
| Environment | Public, customer-facing deployment | Private, permissioned internal workspace |
| Main purpose | Answer questions, guide visitors, capture leads, and represent your brand | Research, create, analyze, automate, and operate across internal workflows |
| Work style | Focused customer conversations | Long-running and multi-step work with planning and todos |
| Agent structure | One customer-facing agent with controlled tools | A main agent with optional specialist sub-agents and handoffs |
| Files and artifacts | Brand knowledge and customer conversation context | Project, agent, and run workspaces with persistent files and generated artifacts |
| Collaboration | Teams configure and review the customer experience | Teammates collaborate with the same agents through shared or private conversations |
| Tools | Knowledge, lead capture, page navigation, web search, and selected safe actions | Powerful tools, skills, connectors, MCP, API requests, files, code execution, and structured output |
| Automation | Responds when customers interact through a deployed channel | Runs manually, through conversations, or automatically on a schedule |

## Choose a Brand Agent for Public Customer Experiences

Brand Agents are designed to become the AI layer on top of your website or customer channel. They can learn from your website, build Brand DNA and a Knowledge Base, answer personalized questions, capture leads, and route visitors to the right page.

![Starting a Brand Agent from a website or manual brand setup](/images/product-ui-2026/brand-agent-create-start.png)

Use a Brand Agent for:

- A public website chatbot or AI receptionist
- Product, pricing, policy, or support questions
- Personalized page navigation across a website
- Lead qualification and contact capture
- Public deployment through website widgets or supported customer channels
- Customer conversations that should follow your brand voice

Because anyone may interact with a public agent, Brand Agents use a deliberately controlled tool surface. Give them only the knowledge and customer-safe actions they need.

## Choose AI Workforce for Powerful Internal Work

AI Workforce is a secure, permissioned agent workspace for you and your team. It is designed for work that may require longer execution, multiple agents, internal tools, reusable files, human decisions, and recurring automation.

![AI Workforce Agent Space with the Project's agents arranged on a live operational floor](/images/product-ui-2026/agent-space-overview.png)

If you have used Claude Code or Codex, think of AI Workforce as giving agents a similar cloud workspace for broader business tasks. An agent can work through directories and files, maintain plans and todos, use powerful tools and connectors, create artifacts, and continue substantial tasks in the cloud. SketricGen adds visual Agent Build configuration, multi-agent orchestration, schedules, traces, and Teamspace collaboration around that work.

Use AI Workforce for:

- Research, content, analysis, sales, support, and operations workflows
- Tasks that may run for several minutes and require multiple steps
- A main agent that delegates focused work to specialist sub-agents
- Project directories, persistent agent files, run files, and generated artifacts
- Planning, todos, traces, and human-input checkpoints
- Internal connectors, MCP tools, API requests, web search, skills, and code execution
- Scheduled reports and recurring automations
- Real-time Teamspace collaboration with shared or private conversations

<Note>
  AI Workforce conversations in a shared Project are public to authorized Project members by default. You can make a conversation private when only you should be able to view it.
</Note>

## You Can Use Both Agent Types

Many teams use both agent types together:

- A Brand Agent acts as the public front door for website visitors and leads.
- AI Workforce agents research, create, analyze, and support the internal team behind that customer experience.

Both can use approved Knowledge Bases, but their default access and interaction models are different. Brand Agents prioritize safe public engagement. AI Workforce prioritizes powerful, transparent, permissioned work for your team.
