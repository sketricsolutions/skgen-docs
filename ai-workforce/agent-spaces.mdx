description: "Understand the current SketricGen distinction between Agent Space for live agent work and Agent Build for configuring internal agent behavior."

SketricGen now separates the operational agent workplace from the internal agent editor.

- [Agent Space](/ai-workforce/agent-space) shows agents, active work, schedules, teammates, and requests needing attention across the selected Project.
- [Agent Build](/ai-workforce/agent-build) configures one agent's main agent, sub-agents, instructions, models, tools, skills, and handoffs.
- [Playground](/ai-workforce/playground) runs and tests that Agent Build through conversations, files, artifacts, traces, and human input.

Older SketricGen documentation used **Agent Space** for the visual builder. The current product calls that configuration surface **Agent Build**. Use the pages above for the current experience.
