AI Workforce is SketricGen's internal agent system for research, marketing, content, sales, support, data, and operations. It combines a live Project workplace, visual agent configuration, conversations, files, schedules, tools, and human control.

Use [Brand Agents](/brand-agents/overview) instead when the main user is a website visitor, prospect, customer, or public-channel audience.

## Core AI Workforce Surfaces

### Agent Space

[Agent Space](/ai-workforce/agent-space) is the live workplace for the selected Project. It shows agents, operational status, teammates, active runs, schedules, and requests that need human attention.

### Agent Build

[Agent Build](/ai-workforce/agent-build) defines how one agent works internally. Configure the main agent, sub-agents, instructions, models, tools, skills, knowledge, and handoffs.

### Playground

[Playground](/ai-workforce/playground) is the Run experience. Start or continue conversations, attach files, observe work, respond to human-input requests, and inspect artifacts and traces.

### Multiplayer AI

[Team Collaboration](/ai-workforce/team-collaboration) connects Agent Space and Playground. Teammates can see who is working with an agent, join a shared conversation, view same-conversation typing indicators, or use parallel sessions with the same Agent Build.

## What AI Workforce Agents Can Do

Depending on the Agent Build and connected permissions, an agent can:

- Plan and complete multi-step work
- Search the web or an approved Knowledge Base
- Use connected business apps
- Call specialist sub-agents
- Read, create, and edit supported files
- Emit schema-validated data through a Structured Output tool
- Pause for human input or approval
- Continue longer-running tasks
- Run manually or on a schedule
- Share operational state with permitted Project members

Capabilities are explicit. An agent can use only the models, tools, skills, knowledge, connections, files, and deployment surfaces available to its Project and Agent Build.

## Typical Uses

- Market, competitor, and account research
- Content planning and production
- Prospecting and outreach preparation
- Sales and meeting preparation
- Internal support and knowledge assistance
- Data analysis and report generation
- Recurring operational checks
- File transformation and structured extraction

## Start From Onboarding or a Template

[Adaptive Onboarding](/getting-started/adaptive-onboarding) can recommend a relevant starting agent after learning your role, business, website, and goal.

Templates provide a prebuilt Agent Build with instructions, agents, tools, setup notes, and test prompts. Review every connection and instruction before using a template with business data.

## Human Control and Transparency

AI Workforce exposes activity through conversations, Agent Space status, traces, and generated files. A workflow can pause for human input before it proceeds.

This visibility helps you distinguish:

- What the user requested
- Which agent handled each part
- Which tools and files were used
- What was generated
- What failed or needs attention
- Which human approved or continued the work when recorded
